В репозиторий загружается **всё содержимое этой подготовленной папки**, включая `.gitignore` и `.env.example`. Не загружать `node_modules`, `.env`, `.local`, пароли, дампы БД, медиа сотрудников. Удалять исходные JS или SQL ради уменьшения числа файлов не нужно.

## Локальная проверка

```sh
npm ci
npm run check
npm test
npm run preview
```

Просмотр: http://localhost:18933. Временная БД создаётся заново при запуске. Тестовый логин записывается в `.local/preview-login.json`; Discord в этом режиме не отправляется. Это демонстрационный режим, для постоянной эксплуатации используйте инструкцию развёртывания.

## Структура

`public/` — страницы и ресурсы исходного сайта; `server/` — API, права, экзамены и доставка; `database/` — последовательные SQL-миграции; `deploy/` — примеры служб и прокси; `tools/` — миграции, первый администратор, проверка; `tests/` — проверки защиты и рабочих сценариев; `docs/` — передача техадминам.
